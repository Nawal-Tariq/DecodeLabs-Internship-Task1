# Responsive Portfolio Website

## Overview
This project was developed as **Task 1** for the **Full Stack Development Internship at DecodeLabs**.

It is a responsive personal portfolio website built using HTML5, CSS3, and JavaScript. The website follows modern web development practices, including semantic HTML, responsive design, accessibility, and interactive user interface components. :contentReference[oaicite:0]{index=0}

## Features

- Responsive design for Mobile, Tablet, and Desktop
- Semantic HTML5 structure
- Mobile-first responsive layout
- CSS Flexbox and Grid
- Interactive navigation menu
- Project filtering by category
- Contact form with client-side validation
- Accessible design using ARIA attributes
